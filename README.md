## 一、游戏概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| **游戏名称** | 智慧小冒险 (Smart Adventure Kids) |
| **游戏类型** | 教育休闲游戏 |
| **目标年龄** | 6-8岁（小学一年级至二年级） |
| **核心玩法** | 答题闯关 + 收集养成 |
| **平台目标** | Web网页（首选）/ PC桌面 / 平板 |

### 1.2 设计支柱（Design Pillars）

1. **趣味优先** - 学习内容必须以游戏化方式呈现，不让孩子感到"这是在学习"
2. **正向反馈** - 每一次正确作答都要让孩子获得成就感和快乐
3. **零挫败感** - 答错不是失败，是"再试一次"的机会
4. **渐进式难度** - 让孩子始终在"舒适区边缘"探索
5. **可见成长** - 孩子的进步要可视化（等级、宠物、地图）

## 二、难度递进系统

### 2.1 难度等级架构

| 等级 | 名称 | 年级对应 | 核心特征 |
|------|------|----------|----------|
| **Lv.1** | 小试牛刀 | 幼儿园大班 | 10以内数感、简单汉字、英语字母 |
| **Lv.2** | 初露锋芒 | 一年级上 | 20以内运算、基本汉字、基础单词 |
| **Lv.3** | 崭露头角 | 一年级下 | 50以内运算、常用汉字、日常词汇 |
| **Lv.4** | 学有小成 | 二年级上 | 100以内运算、词汇拓展、简单句型 |
| **Lv.5** | 学业有成 | 二年级下 | 乘除法入门、短语对话、综合应用 |
| **Lv.6** | 学富五车 | 三年级+ | 乘除法进阶、阅读理解、语法基础 |

### 2.2 难度自适应机制

```
┌─────────────────────────────────────────────────────────────┐
│                    难度自适应逻辑                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  每连续答对 N 题 → 题目难度 +1                              │
│  每连续答错 N 题 → 题目难度 -1 或提供提示                   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  连对3题  →  下一题难度 ↑                            │   │
│  │  连对5题  →  进入「挑战模式」(更丰富奖励)            │   │
│  │  答错1题  →  提供「提示」(不扣分)                    │   │
│  │  连错2题  →  降低难度(返回之前难度)                  │   │
│  │  连错3题  →  触发「鼓励动画」("没关系，再试试!")     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
